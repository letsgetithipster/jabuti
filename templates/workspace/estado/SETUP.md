# SETUP — checklist do onboarding

> Navegação entre threads: toda thread lê este arquivo ao abrir, marca o que
> fechou e termina indicando a próxima thread a abrir.

- [ ] `/jabuti-init` — perfil e política declarada
- [ ] `/jabuti-estrategia` — bandas aprovadas (gera uma linha de micro por classe escolhida)
- [ ] `/jabuti-micro <classe>` — uma thread por classe (linhas adicionadas pelo jabuti-estrategia)
- [ ] `/jabuti-tese <ticker>` — uma linha por ativo escolhido no micro

**Regra do onboarding:** aporte só flui para ativo com tese validada ou ETF.
